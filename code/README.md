# Instruções para compilação e execução do sistema

>[!NOTE]
> Incluir todas as informações necessárias para compilar e executar o programa com sucesso.

## Depedências:
Ubuntu/Debian:

>sudo apt install qt6-base-dev qt6-charts-dev qt6-serialport-dev

Fedora:

>sudo dnf install qt6-qtbase-devel qt6-qtcharts-devel qt6-qtserialport-devel gcc-c++ cmake
